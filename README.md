### About Me

I design and build **production-grade AI systems** that go beyond simple model training. My work spans the full ML lifecycle: from researching architectures and training models to building scalable APIs, multi-agent orchestration pipelines, and interactive dashboards that put AI in the hands of end users.

Currently focused on **agentic AI** — building autonomous systems that plan, execute, evaluate, and self-correct using LLM-powered decision loops.
